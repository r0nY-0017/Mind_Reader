A magical mind-reading game where your thoughts mysteriously choose icons! ✨

## 🎮 How to Play

1. **Pick a number** between 9 and 99
2. **Add both digits** together (e.g., 23 → 2+3=5)
3. **Subtract from original** (23-5=18)
4. **Find your result** in the magical icon grid
5. **Click "Reveal"** to see the magic!

## 🎨 Customization

### Change Icons
Edit the `ICON_SET` array in `script.js` to add/remove icons:

```javascript
const ICON_SET = [
    "fa-star", "fa-heart", "fa-cloud",
    // Add your favorite icons here!
];
```

### Modify Colors
Update the color scheme in `style.css`:

```css
body {
    background: linear-gradient(145deg, #your-color1, #your-color2);
}
```

### Adjust Grid Size
Change the grid columns in `style.css`:

```css
.icons-grid {
    grid-template-columns: repeat(10, 1fr); /* Change 10 to your preferred number */
}
```
